## Последняя важная проблема

Пользователи видели разные задачи, потому что Доска проектов 2 раньше сохраняла задачи в `localStorage` каждого браузера.

Сделаны правки для общего серверного хранения:

- В `server.js` и `server-hotfix.js` добавлен отдельный API:
  - `GET /api/project2`
  - `PUT /api/project2`
- Внутри Доски 2 загрузка и сохранение переключены на `/api/project2`.
- Задачи разных пользователей объединяются.
- Удаления синхронизируются через `deletedTaskIds` и `deletedBacklogIds`.
- При загрузке серверная версия теперь главнее старой локальной копии браузера.
- Добавлено автообновление каждые 5 секунд, чтобы переименования/правки были видны другим пользователям.
- Если открыто модальное окно редактирования, автообновление не перерисовывает доску поверх него.

## Частые места, где были ошибки

- `server-hotfix.js` реально запускается через `npm start`, поэтому правки только в `server.js` недостаточны.
- Встроенный iframe Доски 2 раньше жил отдельно и не всегда корректно общался с родителем, поэтому прямой API `/api/project2` надёжнее.
- Нельзя просто заменять список задач одного пользователя списком другого. Нужно объединять задачи и учитывать удаления.
- Если править только `app.js`, Render при build скопирует его в `public/app.js`, но для локальной проверки лучше держать оба файла синхронными.
